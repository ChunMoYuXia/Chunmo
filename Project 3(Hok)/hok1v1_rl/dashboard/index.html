    先看结果，再找原因

    给强化学习入门者的读图顺序
    01

    胜率回答“会不会赢”

    训练会随机探索，所以训练胜率与 argmax 评估胜率可能不同。先看固定规则评估，再看各英雄和双方阵营。40 局快评波动很大；95% Wilson 区间表示统计不确定性，不能把 9 胜 10 局当成已稳定达到 90%。

    02

    奖励回答“在学什么”

    回报包含经济、伤害、击杀、死亡、建筑与终局等分量。回报升高而胜率不动时，检查是不是只学会刷局部奖励。训练奖励图展示每局均值，不是每步奖励。

    03

    KL 与裁剪观察更新幅度

    KL 衡量新旧策略差异，clip fraction 是进入 PPO 裁剪区的有效动作头比例。长期为零可能是更新很小，也可能是优势弱，不能单凭它决定调大学习率。结合熵、梯度与评估趋势判断。

    04

    熵观察探索，EV 观察估值

    熵表示有效动作头的随机程度，受合法动作数量影响。过早降低可能减少探索。explained variance 接近 1 表示价值预测解释了较多回报波动，低于 0 表示预测比常数基线还差；它不是胜率。

    05

    loss 不必一直下降

    强化学习中策略不断改变，采到的数据也随之改变。policy loss 的正负或 value loss 的短期上升不能直接判定训练好坏。横轴可切换更新数与真实决策数；决策数不包含 LSTM 的 padding。

    06

    先排查数据，再改超参数

    出现未知结果或 Python 截断时，先检查环境与终局判断。英雄样本不均衡时，先检查采样覆盖。旧运行没有逐步状态时，页面只会在对局或更新完成后变化，不代表训练卡死。

    本地数据与评估范围

    独立评估读取当前运行目录下 eval-*/summary.json。指标缺失显示“—”，不会编造数据。当前目标对手是 common AI，英雄池外和真人对战需另行评估。
