# 智能可视化分析报表（AI研报生成器）— 使用说明文档

> 本文档面向系统使用者与开发者，说明系统的功能、架构、安装、配置与操作方式。

## 项目概述

### 项目简介

智能可视化分析报表（AI研报生成器）是一个**面向 A 股个股的一键式智能研报生成工具**。用户输入股票代码，系统自动完成数据获取、技术指标计算、交互式 K 线图绘制，并调用大语言模型生成结构化股评，输出「图表 + 文字」一体的完整研报。

#### 项目意义

##### 技术学习价值

| 技术领域 | 实践内容 | 学习收获 |
|---|---|---|
| 数据工程 | 多数据源对接、容灾降级 | 掌握数据可用性设计 |
| 技术分析 | MA / RSI / MACD 计算 | 理解常见技术指标原理与实现 |
| 数据可视化 | Plotly 交互式图表 | 掌握金融图表绘制 |
| AI 应用 | Prompt 工程、LLM 调用 | 理解结构化输出生成 |
| Web 应用 | Streamlit 快速搭建 | 掌握轻量级数据分析应用 |

##### 架构设计亮点

- **双数据源容灾**：`baostock` 为主、`akshare` 为备，单源故障自动切换，保证数据可用性
- **分层流水线**：数据 → 指标 → 可视化 → AI → 界面，职责单一、解耦清晰
- **Prompt 结构化设计**：股评模板拆成「短期趋势、支撑压力位、风险提示」三段，避免泛泛而谈
- **交互式可视化**：Plotly 提供缩放、悬停、平移等交互能力

##### 实际应用场景

- 个人投资者快速了解个股技术面
- 量化初学者学习数据分析全流程
- 面试项目展示端到端 AI 数据分析能力

#### 核心能力

- 输入股票代码，自动获取日线历史行情
- 计算 MA5/MA10/MA20、RSI、MACD 四个核心指标
- Plotly 交互式 K 线图，叠加均线，副图显示成交量与 RSI
- 大模型根据最新价、RSI、均线位置生成结构化股评
- Streamlit 一站式界面：输入代码 → 点击按钮 → 左侧图表 + 右侧报告
- 研报导出为 PDF（加分项）

### 技术栈

| 层级 | 技术 | 用途 |
|---|---|---|
| 数据获取 | baostock / akshare | 双数据源容灾 |
| 数据处理 | pandas | 清洗、指标计算 |
| 可视化 | plotly | 交互式 K 线图 |
| AI 层 | 大模型 API | 结构化股评 |
| 前端 | streamlit | 一站式界面 |

### 架构设计

#### 系统分层架构

```
数据获取层 → 技术指标层 → 可视化层 → AI报表生成层 → 交互界面层
```

- **数据获取层**：双数据源，自动降级
- **技术指标层**：计算 MA/RSI/MACD，剔除 NaN
- **可视化层**：Plotly 交互式 K 线图
- **AI 报表生成层**：Prompt + LLM 结构化股评
- **交互界面层**：Streamlit 一站式页面

#### 模块说明

| 模块 | 职责 |
|------|------|
| `data_fetcher.py` | 双数据源获取与容灾 |
| `indicators.py` | 技术指标计算 |
| `visualizer.py` | Plotly 绘图 |
| `ai_report.py` | Prompt 模板与 LLM 调用 |
| `app.py` | Streamlit 主界面 |

### 开发与部署

#### 环境要求

| 组件 | 版本 |
|---|---|
| Python | 3.9+ |
| pip | 21+ |
| 操作系统 | Windows / macOS / Linux |

#### 本地安装

```bash
# 1. 创建虚拟环境
python -m venv venv
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置环境变量（.env 或系统环境变量）
# LLM_API_KEY=sk-xxxxxxxxxxxx
# LLM_MODEL=gpt-4o-mini（可选）
```

#### 启动系统

```bash
streamlit run app.py
```

浏览器自动打开 `http://localhost:8501`，输入 `600519`，点击「生成报告」。

## 使用指南

### 生成研报

1. 打开浏览器访问 `http://localhost:8501`
2. 在输入框输入股票代码（如 `600519`）
3. 点击「生成报告」按钮
4. 等待数据获取、指标计算、图表渲染、AI 生成完成
5. 左侧显示 K 线图，右侧显示 AI 股评

### 查看交互式图表

- 悬停查看每日 OHLC 与成交量数据
- 滚轮缩放时间轴
- 拖拽平移查看历史区间
- 图例可开关均线与指标显示

### 导出 PDF

点击「导出 PDF」按钮，系统将图表与股评整合为 PDF 下载。

## 常见问题

### 数据获取失败

- 检查网络连接是否正常
- 确认股票代码格式正确（A 股需带市场前缀，如 `sh.600519`）
- 系统会自动降级到 `akshare`，若仍失败请检查数据源服务

### AI 报告未生成

- 确认已配置 `LLM_API_KEY`
- 确认 LLM 服务可用且配额充足
- 查看控制台日志中的错误信息

### 端口被占用

```bash
streamlit run app.py --server.port 8502
```
