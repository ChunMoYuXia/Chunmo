## 第一章：项目概述与架构设计

### 1.1 教学目标

- 理解项目的业务场景与技术价值
- 掌握分层流水线的整体架构

### 1.2 什么是智能可视化分析报表？

**智能可视化分析报表（AI研报生成器）** 是一个输入股票代码即可一键生成带 K 线图和文字分析研报的工具。

#### 实际应用场景

- 📈 个人投资者快速了解个股技术面
- 🧪 量化初学者学习数据分析全流程
- 🎓 面试项目展示端到端 AI 能力

#### 项目核心能力

1. **数据容灾**：`baostock` 主、`akshare` 备，自动降级
2. **技术指标**：MA5/10/20、RSI、MACD
3. **交互可视化**：Plotly K 线图 + 成交量/RSI 副图
4. **AI 股评**：大模型生成三段式结构化解读

### 1.3 系统架构总览

#### 分层流水线架构

```
数据获取层 → 技术指标层 → 可视化层 → AI报表生成层 → 交互界面层
```

| 层 | 输入 | 输出 | 技术 |
|----|------|------|------|
| 数据获取层 | 股票代码 | 行情 DataFrame | baostock/akshare |
| 技术指标层 | 行情 DataFrame | 含指标 DataFrame | pandas |
| 可视化层 | 指标数据 | Plotly Figure / HTML | plotly |
| AI报表层 | 最新指标 | Markdown 股评 | 大模型 API |
| 交互界面层 | 上述结果 | Streamlit 页面 | streamlit |

## 第三章：数据获取层与容灾

### 3.1 教学目标

- 掌握 `baostock` 与 `akshare` 的行情获取
- 掌握统一接口封装与容灾降级

### 3.2 数据源对比

| 维度 | baostock | akshare |
|------|----------|---------|
| 免费 | ✅ | ✅ |
| 稳定性 | 一般 | 较好 |
| 数据格式 | 规范 | 较杂 |
| 场景 | 主数据源 | 备数据源 |

### 3.3 统一接口实现

```python
import baostock as bs
import akshare as ak

def get_data(symbol, start, end):
    """双数据源容灾获取行情。"""
    try:
        return _get_baostock(symbol, start, end)
    except Exception:
        return _get_akshare(symbol, start, end)

def _get_baostock(symbol, start, end):
    lg = bs.login()
    rs = bs.query_history_k_data_plus(
        symbol, "date,open,high,low,close,volume",
        start_date=start, end_date=end, frequency="d")
    data_list = []
    while (rs.error_code == '0') and rs.next():
        data_list.append(rs.get_row_data())
    bs.logout()
    df = pd.DataFrame(data_list, columns=rs.fields)
    # 类型转换与清理
    df['close'] = df['close'].astype(float)
    return df
```

### 3.4 容灾设计

- 主源异常 → 捕获异常 → 降级到备源
- 备源异常 → 抛出可读错误
- 记录日志便于排查

### 📝 本章小结

- 统一函数签名隔离数据源差异
- 异常捕获实现自动降级
- 容灾是数据可用性的关键

### 4.1 教学目标

- 掌握用 pandas 实现指标计算

### 4.2 MA 移动平均线

```python
def add_indicators(df):
    df['MA5'] = df['close'].rolling(5).mean()
    df['MA10'] = df['close'].rolling(10).mean()
    df['MA20'] = df['close'].rolling(20).mean()
    return df
```

### 4.3 RSI 相对强弱指标

```python
def calc_rsi(close, period=14):
    delta = close.diff()
    gain = delta.clip(lower=0).rolling(period).mean()
    loss = (-delta.clip(upper=0)).rolling(period).mean()
    rs = gain / loss
    return 100 - (100 / (1 + rs))
```

### 4.4 MACD 指标

```python
def calc_macd(close, fast=12, slow=26, signal=9):
    ema_fast = close.ewm(span=fast, adjust=False).mean()
    ema_slow = close.ewm(span=slow, adjust=False).mean()
    dif = ema_fast - ema_slow
    dea = dif.ewm(span=signal, adjust=False).mean()
    macd = (dif - dea) * 2
    return dif, dea, macd
```

### 4.5 剔除 NaN

```python
def add_indicators(df):
    df['MA5'] = df['close'].rolling(5).mean()
    ...
    df = df.dropna()   # 剔除计算指标产生的缺失值
    return df
```

### 📝 本章小结

- MA 是滚动均值，RSI 衡量动量，MACD 衡量趋势
- pandas 滚动窗口与指数加权实现指标
- NaN 行必须剔除以保证下游可用

### 5.2 K 线图 + 均线

```python
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def plot_kline(df):
    fig = make_subplots(
        rows=3, cols=1, shared_xaxes=True,
        row_heights=[0.6, 0.2, 0.2],
        subplot_titles=('K线', '成交量', 'RSI'))

    fig.add_trace(go.Candlestick(
        x=df['date'], open=df['open'], high=df['high'],
        low=df['low'], close=df['close'], name='K线'), row=1, col=1)
    fig.add_trace(go.Scatter(x=df['date'], y=df['MA5'], name='MA5'), row=1, col=1)
    fig.add_trace(go.Scatter(x=df['date'], y=df['MA10'], name='MA10'), row=1, col=1)
    fig.add_trace(go.Scatter(x=df['date'], y=df['MA20'], name='MA20'), row=1, col=1)
    fig.add_trace(go.Bar(x=df['date'], y=df['volume'], name='成交量'), row=2, col=1)
    fig.add_trace(go.Scatter(x=df['date'], y=df['RSI'], name='RSI'), row=3, col=1)
    return fig
```

### 5.3 导出 HTML

### 📝 本章小结
