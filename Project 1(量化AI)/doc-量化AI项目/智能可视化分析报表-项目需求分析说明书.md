## 1. 引言

### 1.1 编写目的

本需求分析说明书旨在全面、准确地描述「智能可视化分析报表（AI研报生成器）」的功能需求、非功能需求、数据需求和接口需求，为项目的开发、测试、验收和维护提供基线依据。

**预期读者：**
- 项目开发人员（数据工程师、后端/前端工程师）
- 系统测试人员
- 项目管理人员
- 系统运维人员

### 1.2 项目背景

在日常个股研究场景中，投资者和量化研究员需要在行情软件、财务网站、技术分析工具之间来回切换，流程割裂且耗时。本项目的目标是将「数据获取 → 指标计算 → 可视化 → AI 文字解读」整合到同一个 Web 界面，实现**输入股票代码后 5 分钟内输出一份带 K 线图和文字分析的完整研报**。

项目采用**双数据源容灾**架构保证数据可用性，利用 **Plotly** 生成交互式图表，并通过**大语言模型（LLM）**基于最新技术指标生成结构化股评，是一款面向个人投资者与量化初学者的端到端数据分析工具。

### 1.3 项目范围

**包含的范围：**
- 股票历史行情数据获取（`baostock` 为主、`akshare` 为备，自动降级）
- 技术指标计算（MA5 / MA10 / MA20 / RSI / MACD）
- 交互式 K 线可视化（主图 + 成交量 + RSI 副图）
- AI 结构化股评生成（短期趋势、支撑压力位、风险提示）
- Streamlit 一站式交互界面
- 研报导出（PDF，加分项）

**不包含的范围：**
- 实时 / 分钟级高频行情
- 财务基本面数据（PE、PB、财报）
- 机器学习预测（交由**项目二：多模型机器学习预测与智能决策**完成）
- 多语言界面与国际市场（仅 A 股）
- 用户注册与多用户权限管理（单用户本地工具）

## 2. 项目概述

### 2.1 项目定位

本系统定位为一款**面向 A 股个股的一键式智能研报生成工具**。它把传统上需要多款软件协作完成的数据分析流程收敛到单一 Web 页面，用户输入股票代码后即可获得数据、图表与文字解读三位一体的研报，显著降低技术门槛与分析成本。

### 2.2 项目目标

| 目标编号 | 目标描述 | 验收标准 |
|---------|---------|---------|
| G-01 | 输入股票代码 5 分钟内生成研报 | 输入 `600519` 后 5 分钟内页面完整渲染图表与文字报告 |
| G-02 | 双数据源自动降级 | `baostock` 无数据时自动切换 `akshare` 重试 |
| G-03 | 计算 4 个核心指标 | `df.columns` 包含 MA5/MA10/MA20、RSI、MACD 列，且无 NaN |
| G-04 | 生成交互式 K 线图 | 输出 `.html` 文件，主图叠加 3 条均线，副图含成交量与 RSI |
| G-05 | AI 生成结构化股评 | 输出包含短期趋势、支撑压力位、风险提示三段内容 |
| G-06 | Streamlit 一站式界面 | `streamlit run app.py` 后输入代码可跑通全流程 |
| G-07 | 研报导出 | 支持将结果导出为 PDF 文件（加分项） |

### 2.3 用户特征与角色

| 角色 | 权限 | 典型用户 |
|------|------|---------|
| **投资者** | 输入代码生成研报、查看图表与文字、导出 PDF | 个人股民 |
| **量化学习者** | 观察数据获取与指标计算过程、复用清洗数据 | 量化初学者、学生 |
| **开发者** | 配置数据源与 LLM Key、运行/部署系统 | 项目开发者、运维 |

> 系统为单用户本地工具，不设登录与多角色权限体系；「角色」仅描述使用视角。

### 2.4 系统架构概述

系统采用**分层流水线**架构，各层职责单一、通过函数接口解耦：

```
┌──────────────────────────────────────────────────────────┐
│                  Streamlit 前端界面层                     │
│          输入框 · 生成按钮 · 图表区 · 报告区 · 导出        │
└──────────────────────┬───────────────────────────────────┘
                       │ 函数调用
┌──────────────────────▼───────────────────────────────────┐
│                    AI 报表生成层（核心）                    │
│        最新指标提取 → Prompt 模板 → LLM 调用 → Markdown     │
└──────────────────────┬───────────────────────────────────┘
                       │
┌──────────────────────▼───────────────────────────────────┐
│                    可视化层（Plotly）                      │
│      K线主图 + MA均线 | 成交量副图 + RSI副图 → .html       │
└──────────────────────┬───────────────────────────────────┘
                       │
┌──────────────────────▼───────────────────────────────────┐
│                  技术指标层（pandas）                      │
│       MA5/MA10/MA20 · RSI · MACD · 剔除 NaN              │
└──────────────────────┬───────────────────────────────────┘
                       │
┌──────────────────────▼───────────────────────────────────┐
│                  数据获取层（容灾）                        │
│        baostock ──失败──▶ akshare（自动降级重试）          │
└──────────────────────────────────────────────────────────┘
```

### 2.5 技术栈

| 层级 | 技术 | 版本 | 用途 |
|------|------|------|------|
| 数据获取 | baostock | — | 主数据源，A 股历史行情 |
| 数据获取 | akshare | — | 备数据源，自动降级 |
| 数据处理 | pandas | 1.5+ | 数据清洗、指标计算、缺失值处理 |
| 技术指标 | ta-lib（可选）/ 自实现 | — | MA/RSI/MACD 计算 |
| 可视化 | plotly | 5.x | 交互式 K 线图与副图 |
| AI 调用 | OpenAI 兼容 SDK / requests | — | 大模型结构化股评 |
| 前端框架 | streamlit | 1.3x | 一站式 Web 界面 |
| PDF 导出 | reportlab / weasyprint | — | 研报导出为 PDF |

## 3. 功能需求

### 3.1 数据获取层（FR-DATA）

#### FR-DATA-01 历史行情获取

| 项目 | 内容 |
|------|------|
| **需求编号** | FR-DATA-01 |
| **需求名称** | 获取股票历史行情数据 |
| **优先级** | 高 |
| **描述** | 根据股票代码和时间范围获取包含日期、开盘、收盘、最高、最低、成交量的数据 |

**功能规则：**
- 函数签名：`get_data(symbol, start, end) -> DataFrame`
- 返回字段：日期、开盘、收盘、最高、最低、成交量
- 数据按日期升序排列
- 结果去除重复日期与全空值行

**验收标准：** 打印 `df.head()` 能看到干净数据，无空值。

---

#### FR-DATA-02 双数据源容灾

| 项目 | 内容 |
|------|------|
| **需求编号** | FR-DATA-02 |
| **需求名称** | 数据源自动降级 |
| **优先级** | 高 |
| **描述** | 主数据源 `baostock` 无数据或异常时，自动切换 `akshare` 重试 |

**功能规则：**
- 优先尝试 `baostock`
- 若返回空数据、抛出异常或超时，自动切换到 `akshare`
- 两个数据源都失败时抛出明确错误信息
- 记录数据源切换日志（用于排查与面试讲述）

**验收标准：** 断掉 `baostock` 数据时仍能获取到数据。

---

### 3.2 技术指标层（FR-INDICATOR）

#### FR-INDICATOR-01 指标计算

| 项目 | 内容 |
|------|------|
| **需求编号** | FR-INDICATOR-01 |
| **需求名称** | 计算核心技术指标 |
| **优先级** | 高 |
| **描述** | 在行情数据基础上计算 MA5、MA10、MA20、RSI、MACD 五个指标 |

**功能规则：**
- 函数签名：`add_indicators(df) -> DataFrame`
- MA：5/10/20 日均线（滚动均值）
- RSI：相对强弱指标（默认 14 周期）
- MACD：DIF、DEA、MACD 柱（默认 12/26/9）
- 计算指标引入的 NaN 行直接剔除

**验收标准：** `df.columns` 能看到新增指标列。

---

### 3.3 可视化层（FR-VISUAL）

#### FR-VISUAL-01 K 线图绘制

| 项目 | 内容 |
|------|------|
| **需求编号** | FR-VISUAL-01 |
| **需求名称** | 交互式 K 线图 |
| **优先级** | 高 |
| **描述** | 用 Plotly 绘制蜡烛图，叠加 MA5/MA10/MA20 三条均线 |

**功能规则：**
- 主图：蜡烛图（OHLC）
- 叠加：MA5、MA10、MA20 三条均线
- 副图一：成交量柱状图
- 副图二：RSI 曲线
- 支持悬停查看数据、缩放、平移

**验收标准：** 运行生成 `.html` 文件，打开能看到漂亮的交互图。

### 3.4 AI 报表生成层（FR-AI）

#### FR-AI-01 最新指标提取

| 项目 | 内容 |
|------|------|
| **需求编号** | FR-AI-01 |
| **需求名称** | 提取最新数据指标 |
| **优先级** | 高 |
| **描述** | 从清洗后的数据集中提取最新一条记录的指标值 |

**功能规则：**
- 提取字段：最新价、RSI 值、MA20 位置（现价高于或低于均线）
- 判断现价相对 MA20 的 above/below 关系
- 判断 RSI 是否处于超买（>70）或超卖（<30）区间

---

#### FR-AI-02 Prompt 模板设计

| 项目 | 内容 |
|------|------|
| **需求编号** | FR-AI-02 |
| **需求名称** | 结构化股评 Prompt |
| **优先级** | 高 |
| **描述** | 设计把最新指标注入的 Prompt 模板，约束 LLM 输出结构化股评 |

**Prompt 模板示例：**
```
你是一名A股分析师。当前股票代码{code}，现价{price}，RSI指标为{rsi}
（大于70超买，小于30超卖），现价位于MA20均线{above/below}。
请根据这些数据，生成一份简短的股评，包含：
①短期趋势判断 ②支撑压力位 ③风险提示。
```

---

#### FR-AI-03 LLM 调用与结果解析

| 项目 | 内容 |
|------|------|
| **需求编号** | FR-AI-03 |
| **需求名称** | 调用大模型生成股评 |
| **优先级** | 高 |

**验收标准：** 打印出 AI 返回的文字，读起来像那么回事。

## 5. 数据需求

### 5.1 数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| date | datetime | 交易日期 |
| open | float | 开盘价 |
| close | float | 收盘价 |

### 7.4 约束条件

1. **数据源依赖**：网络需可访问 `baostock` / `akshare` 数据接口
2. **LLM 依赖**：必须配置至少一个 LLM API Key
3. **数据范围**：仅支持 A 股日线历史数据
4. **指标周期**：RSI 默认 14，MACD 默认 12/26/9
5. **缺失数据处理**：计算指标产生的 NaN 行直接剔除

### 7.5 假设与依赖

1. 假设数据源接口可用且网络连通
2. 假设用户具备基本 Python 运行能力
3. 依赖 pandas、plotly、streamlit 的稳定版本
4. 假设 LLM API 服务可用
