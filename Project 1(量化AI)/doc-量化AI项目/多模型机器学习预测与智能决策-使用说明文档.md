# 多模型机器学习预测与智能决策 — 使用说明文档

> 本文档面向系统使用者与开发者，说明系统的功能、架构、安装、配置与操作方式。本项目基于**项目一（智能可视化分析报表）**生成的清洗数据运行。

## 项目概述

### 项目简介

多模型机器学习预测与智能决策是一个**基于 A 股历史数据的涨跌分类预测与智能决策框架**。它基于项目一生成的技术指标数据，让 3 个机器学习模型（逻辑回归、XGBoost、LightGBM）用时序交叉验证对比表现，自动筛选最优模型并输出上涨概率与投资建议。

#### 项目意义

##### 技术学习价值

| 技术领域 | 实践内容 | 学习收获 |
|---|---|---|
| 机器学习 | 分类建模、多模型对比 | 理解模型评估与选择 |
| 时序分析 | TimeSeriesSplit、防数据泄露 | 掌握时序数据处理 |
| 特征工程 | 标签构造、特征选择 | 理解特征与标签关系 |
| 模型评估 | Log-Loss / AUC | 理解概率与排序评估 |
| AI 应用 | 风控 Prompt、投资建议生成 | 掌握 AI 决策应用 |

##### 架构设计亮点

- **严格时序处理**：70/30 切分不打乱顺序，杜绝未来数据泄露
- **时序交叉验证**：TimeSeriesSplit 保证训练集始终在验证集之前
- **双指标评估**：Log-Loss + AUC 互补，避免单一指标误导
- **多模型擂台**：逻辑回归基准 + XGBoost + LightGBM，自动筛选最优
- **AI 风控建议**：以保守、风险中立语气输出操作建议与风险因素

##### 实际应用场景

- 投资者获取概率化的涨跌判断与风控建议
- 量化学习者理解时序建模与评估严谨性
- 面试项目展示机器学习工程能力

#### 核心能力

- 基于项目一数据构建涨跌分类特征与标签
- 未来第 5 天涨跌预测（分类任务）
- 三个模型对比：逻辑回归（基准）、XGBoost、LightGBM
- 时序交叉验证（TimeSeriesSplit，3 折）评估
- 评估指标：Log-Loss + AUC
- 自动筛选 Log-Loss 最小的模型，预测最新数据上涨概率
- 大模型基于预测概率和 PE 生成风控导向投资建议
- 整合进项目一 Streamlit 的折叠面板排行榜

### 技术栈

| 层级 | 技术 | 用途 |
|---|---|---|
| 数据层 | pandas | 特征与标签构建 |
| 特征工程 | pandas / numpy | 特征筛选 + 时序切分 |
| 模型层 | scikit-learn + xgboost | LR / XGBoost / LightGBM |
| 评估层 | scikit-learn.model_selection | TimeSeriesSplit |
| AI 层 | 大模型 API | 风控导向投资建议 |
| 前端层 | streamlit | 折叠面板展示排行榜 |

### 架构设计

#### 系统分层架构

```
数据层 → 特征工程层 → 模型擂台 → 最优筛选 → AI顾问 → Streamlit界面
```

- **数据层**：项目一清洗数据（含技术指标）
- **特征工程层**：标签构造 + 特征选择 + 70/30 时序切分
- **模型擂台**：统一训练循环 + TimeSeriesSplit
- **最优筛选**：Log-Loss 最小 / AUC 最大 + 最新数据预测
- **AI 顾问**：Prompt + LLM 风控建议
- **界面层**：折叠面板排行榜

#### 模块说明

| 模块 | 职责 |
|------|------|
| `feature_engineering.py` | 特征与标签构建（严格时序） |
| `models.py` | 三个模型定义 |
| `train.py` | 训练循环 + 时序交叉验证 |
| `evaluator.py` | Log-Loss / AUC + 最优模型筛选 |
| `ai_advisor.py` | 大模型投资建议生成 |
| `app.py` | Streamlit 界面（含排行榜面板） |

### 开发与部署

#### 环境要求

| 组件 | 版本 |
|---|---|
| Python | 3.9+ |
| scikit-learn | 1.0+ |
| xgboost | 1.5+ |
| lightgbm（可选） | 3.0+ |

#### 本地安装

```bash
# 1. 创建虚拟环境
python -m venv venv
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置环境变量（.env 或系统环境变量）
# LLM_API_KEY=sk-xxxxxxxxxxxx
# LLM_MODEL=gpt-4o-mini（可选）
```

#### 启动系统

```bash
# 方式一：命令行训练并输出评估结果
python train.py

# 方式二：启动 Streamlit 界面查看排行榜
streamlit run app.py
```

> 运行前需先完成**项目一**生成数据，或使用项目一导出的示例数据。

## 使用指南

### 命令行训练

1. 确认项目一已生成清洗数据（或放置示例数据）
2. 运行 `python train.py`
3. 观察控制台输出每个模型的 Log-Loss 和 AUC
4. 查看最优模型与最新数据预测概率

```
XGB Loss: 0.68, AUC: 0.55
LR   Loss: 0.71, AUC: 0.51
LGB  Loss: 0.70, AUC: 0.53
最佳模型是 XGBoost，推荐置信度 62%
```

### Streamlit 查看排行榜

1. 启动项目一的 Streamlit 页面
2. 生成研报后，向下滚动到「机器学习深度分析」折叠面板
3. 展开面板查看排行榜表格（模型名称、Log-Loss、AUC），最优模型高亮
4. 下方查看 AI 生成的最终投资建议

### 解读评估结果

- **Log-Loss 越低越好**：衡量概率预测的校准程度
- **AUC 越接近 1 越好**：衡量正负类的排序能力
- 若所有模型 AUC 接近 0.5，说明当前特征下预测力有限，需谨慎对待建议

## 常见问题

### XGBoost 安装失败

环境受限时可改用随机森林（sklearn 原生）作为第三个模型：

```python
from sklearn.ensemble import RandomForestClassifier
models['rf'] = RandomForestClassifier(random_state=42)
```

### 数据量不一致

若 `X_train.shape` 与 `y_train.shape` 不一致，检查特征/标签构造时的 NaN 处理是否一致。

### 建议过于激进

- 检查 Prompt 是否包含「保守、风险中立」的约束
- 确认已注入历史胜率与 PE 上下文
- 风控建议应当包含风险因素与轻仓提示

### AI 建议未生成

- 确认已配置 `LLM_API_KEY`
- 查看控制台日志中的错误信息
