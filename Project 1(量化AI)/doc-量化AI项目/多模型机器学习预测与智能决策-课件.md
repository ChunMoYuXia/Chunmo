### 1.2 什么是多模型机器学习预测与智能决策？

**多模型机器学习预测与智能决策** 是基于项目一数据的涨跌分类预测框架，通过多模型对比 + 时序交叉验证评估可靠性，选出最优模型输出上涨概率与风控建议。

#### 实际应用场景

- 📊 投资者获取概率化涨跌判断
- 🧪 量化学习者理解严谨的时序建模
- 🎓 面试展示机器学习工程能力

#### 项目核心能力

1. **特征与标签工程**：未来第 5 天涨跌分类标签 + 历史特征
2. **严格时序处理**：70/30 切分不打乱，杜绝数据泄露

4. **AI 风控建议**：大模型生成保守、风险中立的投资建议

## 第三章：特征与标签工程（严格时序）

### 3.1 教学目标

- 理解标签构造与特征选择
- 掌握时序切分与防数据泄露

### 3.2 为什么是分类任务而不是回归

- 回归预测连续价格误差大
- 分类预测涨跌方向更稳定
- 更符合实际交易决策场景

### 3.3 标签构造

```python
import numpy as np

def build_label(df, horizon=5):
    df = df.copy()
    df['future_close'] = df['close'].shift(-horizon)  # 未来第5天收盘
    df['label'] = (df['future_close'] > df['close']).astype(int)
    df = df.dropna(subset=['label'])  # 剔除因未来缺失产生的NaN
    return df
```

### 3.4 特征选择

```python
FEATURES = ['close', 'MA5', 'MA10', 'MA20', 'RSI', 'DIF', 'DEA', 'MACD', 'volume']

def build_features(df):
    X = df[FEATURES].copy()
    y = df['label'].copy()
    # 删除含 NaN 的行，X 和 y 同步对齐
    mask = X.notna().all(axis=1)
    X, y = X[mask], y[mask]
    return X, y
```

> ⚠️ **重点**：特征**绝对禁止包含未来数据**，只能使用 t 时刻及之前的信息。

### 3.5 时序切分（不打乱）

```python
from sklearn.model_selection import train_test_split

# 按位置切分前70%为训练、后30%为验证
split = int(len(X) * 0.7)
X_train, X_val = X.iloc[:split], X.iloc[split:]
y_train, y_val = y.iloc[:split], y.iloc[split:]

print(X_train.shape, y_train.shape)  # 确认数据量一致
```

> ⚠️ **重点**：**绝对禁止** `shuffle=True`，必须保持时间顺序。

### 📝 本章小结

- 标签为未来第 5 天涨跌（分类）
- 特征只用历史信息，防数据泄露
- 70/30 时序切分，不打乱顺序

### 4.3 时序交叉验证

```python
from sklearn.model_selection import TimeSeriesSplit

def time_series_cv(model, X, y, n_splits=3):
    tscv = TimeSeriesSplit(n_splits=n_splits)
    logloss_list, auc_list = [], []
    for train_idx, val_idx in tscv.split(X):
        X_tr, X_va = X.iloc[train_idx], X.iloc[val_idx]
        y_tr, y_va = y.iloc[train_idx], y.iloc[val_idx]
        model.fit(X_tr, y_tr)
        y_proba = model.predict_proba(X_va)[:, 1]
        logloss_list.append(log_loss(y_va, y_proba))
        auc_list.append(roc_auc_score(y_va, y_proba))
    return np.mean(logloss_list), np.mean(auc_list)
```

### 4.4 统一训练循环

```python
from sklearn.metrics import log_loss, roc_auc_score

results = {}
for name, model in models.items():
    ll, auc = time_series_cv(model, X, y)
    results[name] = {'log_loss': ll, 'auc': auc}
    print(f"{name}: Loss {ll:.3f}, AUC {auc:.3f}")
```

## 第五章：最优模型筛选与预测

### 5.1 教学目标

- 掌握最优模型筛选规则
- 掌握最新数据上涨概率预测

### 5.2 筛选最优模型

```python
def select_best(results):
    # 主指标：Log-Loss 最小
    best_name = min(results, key=lambda n: results[n]['log_loss'])
    # 备选：AUC 最大（Log-Loss 并列时参考）
    # best_name = max(results, key=lambda n: results[n]['auc'])
    return best_name
```

### 5.3 为什么选 Log-Loss 和 AUC

| 指标 | 衡量内容 | 特点 |
|------|---------|------|
| Log-Loss | 概率预测的校准程度 | 越低越好 |
| AUC | 正负类的排序能力 | 越接近 1 越好 |

两个指标互补，避免单一指标误导。

### 5.4 最新数据预测

```python
best_model = models[best_name]
latest = X.iloc[[-1]]  # 数据集最后一行（最新实时数据）
prob = best_model.predict_proba(latest)[0, 1]

print(f"最佳模型是 {best_name}，推荐置信度 {prob*100:.0f}%")
```

> 输出示例：“最佳模型是 XGBoost，推荐置信度 62%”。

### 📝 本章小结

- 以 Log-Loss 最小为主、AUC 最大为备选筛选最优模型
- 双指标互补，避免误导
- 用最优模型对最新数据预测上涨概率
