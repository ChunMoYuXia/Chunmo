# 示例数据

使用客户端“生成演示数据”或 `POST /v1/datasets/synthetic` 生成固定seed的样本。数据含行业共振、停牌、一字涨跌停与现金分红事件，用于流程与异常验证。

合成交易日历只过滤周末，没有还原真实节假日；价格和证券名称均为演示数据，不能用于判断策略有效性。

导入真实行情需要两个CSV：

```csv
代码,日期,开盘,最高,最低,收盘,成交量,成交额,名称,交易所,行业
000001,2026-01-05,10,11,9,10.50,1000,10500,用户提供的名称,XSHE,用户提供的行业
```

```csv
日期,是否交易
2026-01-05,1
```

以上仅为格式示例，日期与价格不是经核验的历史行情。代码按文本保留前导零；价格按人民币元解释；成交量可明确选择股或手，手按100股转换。预检提示错误行、成交额与公司行为缺口，全部错误修正并提供日历后才提交。真实行情、日历和导入缓存保留在运行数据目录，不能上传GitHub。
