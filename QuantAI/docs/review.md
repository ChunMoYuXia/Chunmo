# 需求与架构复核

审阅日期：2026-10-15。对象：用户提供的 5,361 行文档及 workbuddy 的既有审阅、论文对照。两份原文 SHA256 相同，本项目仅存一份原件。本文是工程复核，不是投资建议或正式法律合规意见。

结论：需要调整后开发。完整愿景可以保留，但原文存在会改变费用、净值、历史可见性和交易安全的错误；不能直接把全部服务和论文补丁作为首版开发清单。

## 外部核验依据

1. [上交所股票投资费用说明](https://one.sse.com.cn/onething/gptz/)：过户费成交金额0.01‰双向；规费与佣金的包含关系也需处理。历史生效依据另见[中国结算2022年大事记](https://m.chinaclear.cn/zdjs/dsj/about_dsj.shtml)。
2. [财政部/税务总局2023年第39号公告](https://shanxi.chinatax.gov.cn/web/detail/sx-11400-545-1780448)：自2023-08-28证券交易印花税减半。当前示例不能覆盖此前历史费率。
3. [Tauri 官方 SvelteKit 配置](https://v2.tauri.app/start/frontend/sveltekit/)：SvelteKit 2 / Svelte 5，静态适配与关闭 SSR 的桌面配置。
4. [PostgreSQL16 pgcrypto](https://www.postgresql.org/docs/16/pgcrypto.html)：digest返回bytea，十六进制用encode；不能把文本sha256拼接示意当完整审计实现。
5. [FATH原论文2410.21492](https://arxiv.org/abs/2410.21492)与[错误编号对应论文2509.02718](https://arxiv.org/abs/2509.02718)：后者是高流量多LLM路由。
6. [港交所披露调整说明](https://www.hkex.com.hk/News/Market-Communications/2024/2404122news?sc_lang=en)与[2024-07-26通告](https://www.hkex.com.hk/-/media/HKEX-Market/Services/Circulars-and-Notices/Participant-and-Members-Circulars/HKSCC/2024/ce_HKSCC_NOM_217_2024.pdf)：北向披露机制改变，指标上线前需验证具体来源。

本次重点复核工程契约、关键金融口径与抽查论文。没有完成全部论文原文的可复现实验，也没有声称所有监管与券商规则均已认证；这两者须在对应阶段形成专门证据。

## 方案比较

| 方案 | 取舍 | 判断 |
| ---- | ---- | ---- |
| 模块化单体 + 本地存储 + Svelte/Tauri | 一套领域内核，运行简单，业务边界清楚；需用依赖检查约束模块 | 推荐作为起点 |
| 原文完整微服务 + 多数据库 + K8s | 独立扩容充分，但运维、网络契约与分布式一致性成本高 | 团队与负载明确后逐步拆出 |
| 单体 + 独立研究/任务 worker | 在基础闭环完成后隔离训练/回测负载，部署成本适中 | 推荐的下一阶段演进 |

## 工具与开发准备

现有 brainstorming、frontend-design、TDD、planning、verification 等技能足够，暂不新增 Codex skill。GitHub 连接已通过只读个人资料查询验证，不需重复安装 GitHub 插件。尚未创建或上传任何远程仓库。

当前 PATH 中可用 Git、Node 24、npm、Python 3.14、Docker；未发现 Rust/cargo、uv、gh。所查 Python 环境没有 FastAPI、pytest、NumPy、SciPy、SQLAlchemy、uvicorn。下一阶段依赖安装应在项目自己的环境完成，不污染全局环境。Rust/MSVC/WebView2 是否可构建需进一步检查，不能仅根据 PATH 判定全部组件状态。
