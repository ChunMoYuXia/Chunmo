## 发现与修复

| 发现 | 用户影响 | 修复与测试 |
| --- | --- | --- |
| CSV 裸 `920005` 被通用 `9` 前缀识别为上海 | 北交所代码误标，可能绕过 M0 不支持北交所自动执行的限制 | 先识别 920 北交所，拒绝矛盾显式交易所；领域执行层拒绝旧误标 920。导入 / 冲突 / 旧数据保护回归先出现 4 项失败，修复后定向 21 项全部通过 |
| 编辑组合时，旧保存 / 调仓响应仍可成为当前结果 | 页面显示新草稿，回测 / 风险 / 调仓却使用旧保存版本 | 集中使请求作用域失效，所有编辑及重载均调用；无效权重编辑也取消旧响应。真实组件延迟响应测试先出现 2 项失败，修复后三项通过，包含相同时点切换已保存组合 |

920 号段依据：[北交所启用公告](https://www.bse.cn/important_news/200021629.html)。保留 `900xxx` 的上海标识，不将所有 `9` 前缀都改为北交所。旧版本已误标的数据不会被静默重写；需按正确标识重新导入，自动执行层先行阻断。

放弃旧响应只影响当前界面的版本关联。已经到达服务端的保存仍可能持久化，可以通过已保存组合重载查看；这不宣称撤销已提交的服务器事务。

## 交付核对追加修复

压缩包逐文件 SHA256 核对发现，重复构建时合并复制会遗留旧的带哈希静态资源。修复为完整替换两个明确属于构建的运行时目录，删除前校验固定允许目标与解析后的项目边界；其他目录不受影响。测试先在两个目的地复现旧文件残留，修复后连同越界目标拒绝测试三项全部通过。这是交付核对发现的修复，没有另行派发评审。

真实端到端复跑还发现，后台刷新同一组合记录时会覆盖用户已编辑的回测日期。组件测试稳定复现后，改为按组合 / 数据集 / 日历的逻辑身份初始化日期；相同记录刷新保留草稿，切换组合仍初始化。测试先失败，修复后通过。

CSV 规则修正同时升级 `csv-v2`，将解析器版本纳入内容身份；相同文件重新导入不会复用 `csv-v1` 的错误证券映射。旧版本保持不可变，并继续由执行层阻断误标 920；版本隔离测试先失败后通过。
